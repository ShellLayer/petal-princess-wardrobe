# 3.0 千年华服衣橱：验证记录

验证日期：2026 年 11 月 14 日。对象为当前源码及重新构建的 `花间小公主.html`。

## 自动化

`npm test`：**14 项通过，约 10 秒**。

1. 默认进入中国人物与汉风装扮，192 个选择可通过每页六件的界面全部访问。
2. 朝代衣橱分组可用，宋辽夏金元组分别呈现北宋、南宋、辽、西夏、金、元；先秦组显示商周、春秋、战国。
3. 八个类别独立更换，配件可取下、撤销，重载保存结果。
4. 对 **24 双鞋逐一渲染**，检查左右鞋底及不同鞋款的实际像素落地位置一致，数据见 `鞋履像素对齐.json`。
5. 检查 **36 张衣装图脚部区域完全透明**；更换衣装仍使用同一张人物脸部和同一组脚踝坐标。
6. 多图层照片生成、PNG 文件签名、实际下载、相册恢复通过。
7. 浏览器断网，使用 file:// 打开单文件版，后几页的新衣装、头饰、小物及拍照可用，没有 HTTP 请求。
8. v1 / v2 旧记录及相册保留，新版首次进入古风默认形象。
9. 损坏或被禁用的本地存储不阻断换装，临时收藏有提示。
10. 素材读取失败后，重试入口可恢复。
11. 键盘、大画面、按类别特写、重复选择同一请帖正常。
12. 休息提醒排除弹窗停留时间，结束后重新计时。
13. 360 × 800 手机视口可浏览后续页面；选择鞋子时人物仍在视口中，卡片大于 130 × 170 CSS px，无横向溢出。
14. 1440 × 1050 桌面与 1024 × 768 平板布局通过，无外部资源请求，减少动画模式不产生星星动画。

预览与照片共用 `character-renderer.js`，而不是分别维护一套对齐逻辑。定位参数记录在 `ancient-data.js` 的统一人物坐标中。测试还检查了截图、配件取下后的空图层、相册及旧版本数据迁移。

另在 Chrome、Edge 中设置 4 倍 CPU 减速，逐页换装，等待目标衣装就绪并经过两次画面刷新后计时。随后验证了嫦娥、多配件照片生成。未捕获到脚本异常。

这只是本机无头浏览器模拟减速观察，不是对某个真实旧电脑、手机帧率或内存下限的保证。未开展真实低端机测试。
