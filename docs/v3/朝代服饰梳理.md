# 中国古装衣橱：历史范围、可用形制与依据

整理日期：2026 年 11 月 14 日。用途是为幼儿换装游戏建立衣装和配件库，不是绘制服饰考古复原图。

## 梳理方式

中国服饰不能只列唐、宋、明、清，也不能简单理解成一个王朝只有一种衣服。同一时期有地域、族群、身份、年龄和用途差异，不少形制跨朝代延续。宋、辽、西夏、金应分别呈现，清代满族旗装与汉族女装也应分开。

以中国国家博物馆的[中国古代服饰文化展](https://www.chnmuseum.cn/portals/0/web/zt/202102gdfsh/)作为通史框架；该展还包含战国深衣木俑、汉代女舞俑、南北朝女俑等图像和实物线索。游戏另按下面的较细时期组织，而不是只沿用展览的六个大分区。

本次已制作 30 套中国风新衣装，其中 28 套为朝代灵感、2 套为神话主题，另保留原有 6 套童话裙装。下表列明本轮制作方向与暂未制作的时期，实际条目见 `素材清单.json`。配色、尺寸和纹样作儿童绘本化处理；图像展示为“朝代灵感”，不是声称每一套都是当时公主或幼童的真实着装。

| 时期 / 政权 | 可转化的衣装方向 | 可搭配元素 | 本次安排与边界 |
| --- | --- | --- | --- |
| 新石器时代 | 纺织、缝纫起源与自然材料 | 骨针、纺轮、早期佩饰 | 可做文化介绍；不凭工具拼出一套确定的公主服 |
| 夏 | 早期衣裳与佩饰主题 | 玉饰、织带 | 本轮尚未核实到足以支持独立女装细节的材料，暂未绘制 |
| 商 / 西周 | 上衣下裳、宽带、几何纹缘饰的艺术转化 | 笄、玉佩、几何织带 | 已入库“商周·云纹衣裳”；具体纹样为现代转化 |
| 春秋 | 周风衣裳与交领、腰带组合 | 组佩、带钩、笄 | 已入库“春秋·青黛衣裳”；不把各国衣冠合为精确同制 |
| 战国 | 楚地深衣、长衣与交叠衣缘 | 组玉佩、凤鸟纹、带钩 | 已入库“战国·楚韵长衣”；有深衣木俑可参考 |

| 三国 | 汉末延续的襦裙与交领衣 | 双丫、腰带 | 已入库“三国·紫苏襦裙”；不凭颜色虚构魏蜀吴三套唯一国服 |
| 西晋 | 宽袖襦、裙与层叠衣缘 | 簪、发带、腰绦 | 已入库“西晋·竹影宽袖”；儿童化改绘 |
| 东晋 | 宽博衣裙、飘带的图像灵感 | 高髻、垂带 | 已入库“东晋·清风衣裙”；古画摹本只能作图像参考 |
| 南朝宋齐梁陈 | 杂裾、垂髾、宽袖与长裙方向 | 环髻、长带、玉饰 | 已入库“南朝·流霞杂裾”；暂合为一组，不强行拆成四套 |
| 十六国、北朝早期 | 胡汉服饰交流中的短衣、裤褶与长裙 | 靴、带具、束发 | 继续列为扩充来源；不自动等同于全部北朝 |

| 民国 | 近现代旗袍、文明新装等 | 发箍、布鞋、手袋 | 可作为未来“近代”专题，不归入本次古代朝代库 |
| 神话与节令 | 嫦娥、花神、敦煌舞乐等童话主题 | 月轮、莲花、云纱、灯笼 | 单独标为“神话 / 节令灵感”，不冒充某朝代日常服 |

## 补充依据与解释限度

- [中国丝绸博物馆：一物 Vol.38《素罗单衣》](https://www.chinasilkmuseum.com/yg/info_13.aspx?itemid=28354)：可查宋代罗衣与褙子的实物个例。具体绣边、薄纱和搭配不一律套到所有朝代。
- [故宫：《清明上河图》卷新探](https://www.dpm.org.cn/journal/247214.html?_list=1)：讨论北宋早中期、崇宁大观时期与南宋褙子的变化，支持把宋代内部差异留下来。
- [中国丝绸博物馆：辽元服饰修复展](https://www.chinasilkmuseum.com/cs/info_164.aspx?itemid=4493&parent=)：实际展品包括辽锦袍、童靴、锦袋及元腰线袍、荷包等，可同时扩充衣装、鞋履和小物。
- [中国丝绸博物馆：金元时期《文姬归汉图》中的服饰与年代问题](https://www.chinasilkmuseum.com/kydt/info_210.aspx?itemid=27960)：支持区分“故事时代”与“画中衣装时代”，避免照题名误配朝代。
- [北京服装学院：金代女真服饰复原对象](https://msxy.bift.edu.cn/xwdt/875ed3c8a8ea449eb000b60eea428046.htm)：说明可参考阿城金代齐国王墓服饰实物。
- [《汉至唐服饰文化交流的考古学观察》](https://cssn.cn/skgz/bwyc/202607/t20260715_6059266.shtml)：讨论北朝窄袖、高腰间色裙、裤褶等形制及其交流背景。
- [故宫：顾恺之《女史箴图》宋摹本](https://www.dpm.org.cn/collection/paint/231643.html)：登记明确为摹本；本游戏只把它当衣裙图像线索，不能直接当作东晋原衣实物。
- [故宫：从《韩熙载夜宴图》看五代服饰](https://minghuaji.dpm.org.cn/article/detail?id=47&paintId=cf079fc653b94f08bde56dfe7df84fc6)：可学习唐宋之际图像，但现存画本的年代和临摹问题要保留。
- [西夏武威墓木板画研究，作者包含武威市文物考古研究所研究人员](https://ygx.sxu.edu.cn/db/%E6%9C%9F%E5%88%8A/20260417/97%E4%BB%A5%E7%94%BB%E8%AF%81%E5%8F%B2%EF%BC%9A%E6%AD%A6%E5%A8%81%E8%A5%BF%E5%A4%8F%E5%A2%93%E5%87%BA%E5%9C%9F%E6%9C%A8%E6%9D%BF%E7%94%BB%E7%9A%84%E5%A4%9A%E7%BB%B4%E5%8E%86%E5%8F%B2%E4%BB%B7%E5%80%BC%E7%A0%94%E7%A9%B6.pdf)：作为西夏服饰的补充图像资料，本次使用的是艺术方向参考，不声称完整考证了全部女服。

## 素材使用

本次网络检索用于确认历史范围、可参考形制和博物馆线索。检索到的网页图片没有自动获得可再发布许可，因此不把博物馆照片直接当游戏贴图打包。游戏使用本项目原创生图和原生 SVG 配件，并记录来源方向、生成提示词、实际图层与对齐数据。
