# 花间小公主：设计调研与实施

调研及制作日期：2026 年 11 月 14 日。

本页保留面向幼儿的交互设计依据。3.0 新增中国人物、历史时期衣橱和大量古风配件，当前范围见 [朝代服饰梳理](v3/朝代服饰梳理.md)、[素材清单](v3/素材清单.json)和 [验证记录](v3/验证记录.md)。

## 设计目标

面向 3 岁左右孩子的自由换装玩具。孩子通过看图和点击表达“我喜欢”，家长可以共同命名颜色、描述服装、编故事。当前版本不宣称经过幼儿测试，也不承诺教育或发展效果。

## 调研依据

1. [Sesame Workshop：学龄前儿童触屏体验设计](https://joanganzcooneycenter.org/publication/best-practices-designing-touch-tablet-experiences-for-preschoolers/)。报告介绍基于 50 余项研究的经验，强调为不识字的幼儿提供视觉和语音支持，点击比复杂手势更直观，同时提醒避免把容易误触的入口紧贴屏幕底边。**本项目据此采用看图点选，不要求拖拽或捏合；语音可选，选中状态有勾选和边框。**
2. [NN/g：按儿童身体发展阶段设计](https://www.nngroup.com/articles/children-ux-physical-development/)。研究覆盖 3–12 岁儿童，指出幼龄儿童的精细操作有限；建议大而明显的触摸目标，桌面交互尽量用简单点击。文章建议幼儿触控目标约 2 cm 见方。**本项目把主要物品卡片做得远大于一般网页按钮，类别入口约 72–79 CSS px 高，并留出间隔。CSS 像素不等于实际厘米，仍需在目标平板实测。**
3. [UNICEF Innocenti：RITEC 儿童数字游戏框架](https://www.unicef.org/innocenti/projects/responsible-innovation-technology-children)。框架重视自主选择、创造、身份表达与安全。**这里转化为自由组合、没有输赢和外貌评分，以及不设置广告、购买或社交入口。**这是产品设计的应用判断，并非对 3 岁人群效果的直接验证。
4. [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)。2.5.7 提供不依赖拖拽的操作路径；2.5.8 规定指针目标的最低尺寸或相应间隔要求。**项目以完整按钮提供操作，并加入键盘焦点、标签、动态状态说明和减少动画支持。**没有开展完整 WCAG 合规审计，不把单一尺寸达标当作整体无障碍认证。

## 已实施的交互

- 打开即玩，没有账号、开始菜单或关卡选择。
- 核心只有“类别 → 图片 → 立即换上”。不依赖文字理解。
- 类别使用裙子、王冠、魔法棒和风景图标，配简短中文。
- 衣裳、鞋子、发型、头饰、面罩、披帛、小物、场景共八个类别。3.0 每页最多 6 个选择，使用大按钮翻页；桌面为六宫格，手机为两列大图片，保持人物可见。
- 每次变化可见；轻微星星只在操作后短暂出现，不循环闪烁。可以关闭动画。
- 每次搭配都被接纳，不设“漂亮程度”、星级或排行榜。
- 选错可点另一个，或用回退按钮撤销。头饰和小物都能摘下。
- 拍照后可回到游戏、收藏或下载；收藏不自动触发下载。
- 声音和朗读默认关闭，由家长或玩家主动开启。
- 休息提醒默认关闭，可按家庭安排选择；弹窗提供休息提示，不使用连续游玩奖励。
- 默认放大人物、物品图片、类别按钮和文字，另有进一步放大模式；选择鞋子、面罩或发型时可查看对应部位的特写。
- 三张童话邀请函提供装扮与讲故事的起点，选中后仍可任意改装，不判断是否搭配正确。

## 美术与低配置方案

采用原创儿童绘本角色，六套服装同姿势、同角色。2.0 将基础裙装与发型、鞋子拆开，发型使用单独生成的透明绘本图集；鞋子、头饰、面罩、翅膀、手持物分别叠加。三个场景来自同一绘本背景图集。游戏不进行实时布料或发丝物理模拟。

美术使用本次内置生图工具制作，未从第三方游戏或动画中搬运角色。原图保留在 assets 中；发布使用压缩 WebP 图集和缩略图。无在线字体、3D、视频、联网生图或分析 SDK；动画只有事件触发时的少量 CSS 元素。后台不累计提醒时间。

桌面布局为左侧大人物、右侧大衣橱；窄屏依次排列角色和衣橱，人物预览和类别入口在滚动时保留可见。手机物品改为两列，放大单张图片。横向平板可同时看到两区。放大旨在提高可见性和操作便利，不宣称医学意义上的护眼效果。

## 下一轮最有价值的验证

邀请家长陪同 3 岁孩子试玩 5–10 分钟，记录：

1. 不口头指导时，能否发现裙子图片可以点击。
2. 能否发现八个类别；是否把图标误认为可穿戴物品，是否需要简化类别数量。
3. 是否频繁误触相邻物品，主角和衣橱是否都在舒适视线内。
4. 对音效、语音、星星反馈的偏好，是否分散注意。
5. 是否能在成人提示下理解拍照和回退。

这里只建议观察性试玩，不把操作成功率写成已经获得的证据。优先根据实际困难调整图片、按钮和类别，再考虑增加角色或更多衣服。
