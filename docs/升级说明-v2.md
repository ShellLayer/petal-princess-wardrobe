# 花间小公主 2.0：更多搭配，更大的画面

本次根据“增加换鞋、头饰、面罩、发型，并放大内容”的反馈完成。

## 八个独立类别

| 类别 | 内容 |
| --- | --- |
| 裙子 | 六条绘本公主裙 |
| 鞋子 | 蝴蝶鞋、水晶鞋、珍珠鞋、星星鞋、叶子鞋、芭蕾鞋 |
| 发型 | 长卷发、双辫、金色短发、丸子头、高马尾、黑亮长直发 |
| 头饰 | 王冠、花环、星星皇冠、蝴蝶结、雏菊发箍，可摘下 |
| 面罩 | 蝴蝶、猫咪、星星、兔兔、月亮舞会面罩，可摘下 |
| 翅膀 | 花瓣、蓝天、森林、月光、暖阳天使翅，可摘下 |
| 小物 | 魔法棒、花束、气球等，可放下 |
| 仙境 | 花园、城堡、月光仙境 |

所有类别可分别更换。撤销、随机搭配、相册和照片都包含新类别。上一版的裙子、头饰、小物、场景记录和旧相册会保留，新鞋款按原裙子配色补上。

## 更大的画面

默认就放大了公主、物品图片、按钮与文字，压缩顶部留白。桌面物品文字从原来的约 11 px 提升到 15–17 px，图片从约 89 px 提升到 124–147 px。手机物品从三列改为两列，保留公主预览与类别入口。

右上“再大一点”提供更大的尺寸，并保存设置。舞台“放大看看”按当前类别显示脚部、头部或衣服特写，再点“看全身”返回。拍照始终保存完整装扮。

放大用于提高可见性与操作便利，没有把界面尺寸变化当作已验证的护眼效果。

## 一起编童话

“童话邀请”有花园茶会、星光舞会、云端旅行三个故事起点。点邀请函即可换上一套主题装扮，随后可以继续任意改装，不评分、不判断对错。
