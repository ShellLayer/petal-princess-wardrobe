# 在不同设备上玩花间小公主

## 在线打开

电脑、手机或平板用浏览器访问：

**[花间小公主在线试玩](https://shelllayer.github.io/petal-princess-wardrobe/)**

不需要安装软件，也不需要 GitHub 账号。网页由 GitHub Pages 托管，原来的电脑可以关机。第一次进入需要联网下载图片；本版本没有离线缓存管理，断网游玩请使用下面的单文件版。

手机可在浏览器菜单中选择“添加到主屏幕”或类似选项；菜单名称随系统和浏览器变化。它是方便打开网页的快捷入口。

## 换装和拍照

1. 点衣裳、鞋子、发型等类别，再点大图片。
2. 点彩色圆圈换颜色，点“原”恢复原色。颜色按类别分别保留。
3. 用“朝代衣橱”筛选时期；用上一页、下一页看更多。
4. 用“放大看看”检查头部、衣服或鞋子，“看全身”返回。顶部“再大一点”放大界面。
5. 用“惊喜搭配”或“游园请帖”开始一个穿搭故事。
6. 点“拍张照片”，可以保存图片或放进本机相册。弯箭头可撤销刚才的选择。

家长小角落可以设置声音、中文朗读、安静画面和 5 / 10 / 15 分钟的休息提醒。声音、朗读和休息提醒默认关闭。

## 离线文件

在 [下载页面](https://github.com/ShellLayer/petal-princess-wardrobe/releases/latest) 获取离线压缩包，解压后双击 `花间小公主.html`。也可以把这一个 HTML 文件复制到其他电脑，不需要携带素材文件夹。

手机和平板的文件预览器不一定支持完整网页脚本和图片保存，优先从在线网址进入。浏览器不支持直接保存照片时，可以截图保留装扮。

## 不同设备的相册

游戏没有云端账号。搭配、相册与设置只留在当前设备的当前浏览器，换设备或换浏览器不会自动带过去。清除网站数据、使用隐私模式，也可能让记录消失。想长期保留或在别的设备查看，请把喜欢的搭配保存为图片。

在线版和下载的离线版也可能使用不同的本机存储空间。旧版相册可在原来的浏览器或文件里继续打开。
