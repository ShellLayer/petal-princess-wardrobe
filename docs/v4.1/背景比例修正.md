# 4.1.1 背景比例修正

问题来源是舞台、场景卡片和请帖使用了强制铺满宽高的背景样式，照片也直接将竖版背景拉成了 720×930。不同画框比例会使月亮、亭子和树木变形。

现改为等比铺满并裁切边缘。舞台、场景卡片、请帖与照片使用同一组取景位置；两幅月景向上取景以保留月亮。服饰与人物的位置不变，沿用原来的手部图片。

已检查桌面、平板和手机画面及月宫照片。相关四项自动检查通过：照片保存与相册恢复、完全离线单文件、手机操作、桌面和平板布局。
